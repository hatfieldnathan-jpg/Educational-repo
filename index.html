Recommended GitHub Repository File Structure

To host this portal seamlessly on GitHub Pages, organize your repository root as follows: 

my-poki-portal/
├── index.html               <-- (This Main Portal Application)
└── Games/                   <-- (Folder containing all game HTML files)
    ├── archers.html         <-- Game #1
    ├── racing.html          <-- Game #2
    ├── puzzle.html          <-- Game #3
    └── runner.html          <-- Game #4
Adding New Games

Simply click the "Add Game Card" button in the header bar. Enter your game title, target file path (e.g. ./Games/mygame.html), and category. It instantly adds a card to the grid!

Deploying to GitHub Pages

Commit your changes, push to GitHub, and enable GitHub Pages under Settings > Pages > Branch: main. Your portal will be live globally!
